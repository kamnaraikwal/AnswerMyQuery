# Vibe-Talker

Vibe-Talker is a voice-controlled AI coding assistant for Windows. It listens through the microphone, converts speech to text, sends the request through a LangGraph agent, and can execute shell commands and return the results.

## Features

- Continuous speech recognition from the default microphone
- Google Gemini-powered AI responses
- LangGraph tool-calling workflow
- MongoDB-backed conversation checkpoints
- Shell command execution on Windows
- Ambient-noise calibration before listening
